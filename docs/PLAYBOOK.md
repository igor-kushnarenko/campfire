# Плейбук: интерактивная пиксельная сцена (по опыту campfire)

## 1. Заготовка
- Репо на GitHub, включить Pages, Actions-деплой на push в main.
- Vite + Three.js: сцена из PNG-слоёв на плоскостях, сверху пиксельный шейдер.
- `node --test` для логики без браузера.

## 2. Арт и слои
- Слои с номерами (`01_bg` … `11_front`) в двух размерах: `aligned` и `half`.
- Объекты, которые должны быть перед эффектами (огонь/дым/свет), — маска по силуэту, а не горизонтальный клип.
- Координаты интерактивных точек — в объекте `P` в `main.js`.

## 3. Анимация и эффекты
- Огонь/свет — шейдеры и спрайты. Проверять пиковые состояния, не только среднее.

## 4. Интерактив
- Hover — через `window` `pointermove`, чтобы обработчики слоёв не перебивали.
- У кнопок: подсветка при наведении + индикатор состояния.
- Колесо мыши и стрелки пульта — переключатели.

## 5. Звук (WebAudio)
- Процедурный фон (треск, ветер, дождь), у каждого свой регулятор.
- Внешние потоки: `<audio crossOrigin>` → MediaElementSource → gain → компрессор → master; запасной плеер без CORS.
- Громкость подбирать короткими итерациями на слух владельца.

## 6. Контент (станции)
- JSON-выгрузки radio-browser → `node tools/merge_stations.mjs stations_in/*.json` (только https, без HLS, без дублей).
- Нерабочие станции тюнер пропускает; без интернета — только шум.

## 7. Интерфейс
- Меню в круглой кнопке ☰: раскрывается при наведении, сворачивается через 5 с.
- Настройки — `settings.js` (localStorage).

## 8. Цикл правки
1. Задача (скриншот, если визуально).
2. Правка → тесты → сборка → при необходимости headless-скриншоты.
3. Push в main после «да» → `gh run list -L1`.
4. Проверка на сайте, обратная связь.

## 9. Чек-лист релиза
- Слои не перекрываются неправильно на пиковых эффектах.
- Hover и клики работают на всех кнопках.
- Звук без перегруза, помехи и фон слышны.
- Работает на телефоне и на ТВ с пульта.
- Нет секретов в репо.
